# JCVH — Prototipo web

Repositorio inicial para el proyecto educativo **Jóvenes Contra la Violencia Honduras (JCVH)**, coordinado mediante **Orchestor**.

> **Aviso:** prototipo independiente, sin afiliación institucional confirmada. No utilizar datos personales reales, fotografías de personas identificables sin autorización ni contactos o cifras institucionales no verificados.

## Documento de requisitos

Consulta [`PROJECT.md`](./PROJECT.md) para el alcance funcional, las seis ciudades de referencia, enlaces aportados, criterios de aceptación y restricciones de privacidad.

La dirección visual inicial queda deliberadamente abierta para que Orchestor y sus agentes propongan el diseño. No hay código de aplicación ni despliegue todavía.

## Estado

- Fase actual: inicialización documental (F0 pendiente de desarrollo).
- Framework propuesto: React + Vite + React Router.
- Datos de demostración: JSON Server con `db.json` sintético.
- Ejecución de agentes, push de código de aplicación, integración de IA y despliegue: requieren autorizaciones separadas.
